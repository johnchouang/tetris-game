# AutoDev Prompt - Tetris Game

## Project Overview
Production-ready Tetris game implementation in a single HTML file with inline CSS and JavaScript.

## Key Requirements
- Single `index.html` file with all HTML, CSS, and JS
- Neon-on-dark arcade aesthetic using "Press Start 2P" font
- Canvas-based rendering for playfield and pieces
- Complete game logic including scoring, levels, and piece mechanics

## File Structure
- `index.html` - Main game file
- `task_plan.md` - Task breakdown
- `findings.md` - Technical decisions
- `progress.md` - Phase progress tracking

## Implementation Phases
1. HTML Structure & CSS Styling ✅
2. Game Constants & State
3. Audio System
4. Input Handling
5. Game Logic
6. Rendering System
7. UI & Stats
8. Polish & Testing

## Technical Specifications
- CELL_SIZE: 28px
- BOARD_WIDTH: 10
- BOARD_HEIGHT: 20
- Canvas: 280×560
- Color palette: Cyan (#00f5ff), Pink (#ff0055), Yellow (#ffe500)

## Input Controls
- Arrow keys: Movement and rotation
- Space: Hard drop
- C/Shift: Hold
- P/ESC: Pause
- R: Restart
